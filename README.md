# AI Resume Analyzer

An AI-powered web application that analyzes resumes against job descriptions and provides intelligent feedback, ATS-style evaluation, and candidate-job matching insights.

## Features

* Upload resume PDFs
* Convert PDF resumes into readable format
* Analyze resumes using AI
* Compare resumes with job descriptions
* ATS-style scoring and feedback
* Clean and responsive UI
* Fast resume processing

## Tech Stack

* React
* TypeScript
* Remix
* Tailwind CSS
* PDF.js
* AI Integration

## How It Works

1. Upload your resume PDF
2. Enter company name, job title, and job description
3. AI analyzes the resume
4. Get feedback, matching insights, and evaluation results

## Installation

```bash
git clone <your-repo-link>
cd ai-resume-analyzer
npm install
npm run dev
```
